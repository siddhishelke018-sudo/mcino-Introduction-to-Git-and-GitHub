   # Introduction to Git and GitHub

   A simple interest calculator project for learning Git and GitHub.

   ## Simple Interest Calculator
   The `simple-interest.sh` Bash script calculates simple interest from user input:
   - Principal amount (p)
   - Annual rate of interest (r)
   - Time period in years (t)

   Formula: Simple Interest = (p × t × r) / 100

   ## How to run
   bash simple-interest.sh
